A portfolio-style collection of **front-end UI projects** built with **HTML, CSS, and vanilla JavaScript**. This repository focuses on learning-by-building: layouts, animations, responsive components, DOM manipulation, and small interactive apps.

## Repository Overview

- **Purpose**: practice modern front-end fundamentals through small, isolated projects that are easy to review and showcase.
- **Focus areas**: responsive UI, CSS effects/animations, DOM events, form validation, and lightweight client-side logic.

## Statistics

- **Total Projects**: 20
- **HTML/CSS Projects** (layout/animation focused): 14
- **JavaScript Projects** (interactive apps/components): 6

## Skills Demonstrated

- **HTML**: semantic structure, form inputs, accessibility-friendly attributes, layout scaffolding.
- **CSS**: flexbox, responsive design, media queries, transitions, keyframe animations, gradients, sticky positioning, glassmorphism.
- **JavaScript**: DOM selection + manipulation, event handling, timers (`setInterval`), dynamic element creation, validation, conditional rendering, API fetch.
- **UI/UX**: feedback states, focus/hover interactions, readable layout spacing, responsive breakpoints.

## Learning Journey

These projects show a clear progression:

- starting with **static UI components** (menus, loaders, clones),
- moving into **responsive layouts** (navbars and mobile tweaks),
- then into **interactive DOM-driven apps** (to-do, expense tracker, overlay modals),
- and finally into **API-driven UI** (weather app with dynamic background and date formatting).
