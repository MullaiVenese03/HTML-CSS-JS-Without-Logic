## Features

- **Animated gradient** that shifts across the screen using `background-size` + keyframes.
- **Centered glass card** using transparency, blur, and shadow effects.
- **Minimal markup**: one card element on top of a dynamic background.

## Technologies Used

- HTML5
- CSS3 (gradients, keyframes, glassmorphism)

## What I Learned

- **CSS**: animating backgrounds using `background-position` and oversized gradients.
- **UI/UX**: using a translucent card to improve text readability on animated backgrounds.

## Challenges Faced

- **Performance vs smoothness**: ensuring the animation feels fluid without being distracting.
- **Readability**: keeping text legible over a constantly shifting gradient.

## How I Solved Them

- Used a short, repeating keyframe animation with controlled easing.
- Added a **semi-transparent card** with blur and shadow to isolate the content.

## Future Improvements

- Add reduced motion support (`prefers-reduced-motion`).
- Add more card content (buttons/links) to turn it into a landing hero section.
