## What I Learned

- **CSS animation fundamentals**: keyframes, transitions, timing functions, and hover-driven motion.
- **Responsive layouts**: media queries, flex direction changes, and mobile-friendly stacking.
- **Reusable UI patterns**: navbars, loaders, inputs, and cards that translate to real apps.
- **Visual design**: contrast, spacing, shadows, and simple component composition.

## Installation

```bash
git clone https://github.com/MullaiVenese03/HTML-CSS-JS-Without-Logic.git
cd "HTML-CSS-JS-Without-Logic/Mini-Projects"
```

Open any project’s `index.html` in a browser.
